## 🚀 Quick Start Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ranakeyur-31525/COMPLETE_AWDF.git
   cd COMPLETE_AWDF
   ```

2. **Run any practical individually**:
   ```bash
   npm run p1      # Runs Practical 1 on http://localhost:5171
   npm run p4      # Runs Practical 4 on http://localhost:4004
   npm run p7      # Runs Practical 7 on http://localhost:5007
   npm run p13     # Runs Practical 13 on http://localhost:5013
   ```

3. **Run CI/CD Tests locally**:
   ```bash
   npm run p12:test
   ```
